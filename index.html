WebKit layout bug reproduction

A position: fixed descendant of a z-indexed element is clipped to body's box when html and body have overflow: hidden. See the bug report.

Test cases

  • minimal.html: the minimal test case
  • minimal-body-height-548px.html: body { height: 548px; }

Variants

  • minimal-body-height-300px.html: body { height: 300px; }
  • minimal-body-height-100vh.html: body { height: 100vh; }
  • minimal-no-overflow.html: no overflow: hidden
  • minimal-cover-absolute.html: #cover is position: absolute
  • minimal-wrapper-fixed.html: #wrapper is position: fixed
